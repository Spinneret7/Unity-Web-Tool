# Unity-Web-Tool
Command Line Unpacker for .Untiy3d files with Unity Web Header formats.
This Tool can extract Unity Web heading file which Uses Only **Lzma**, lz4 is not included as it's way common as could be unpacked with any simple tool on the internet. It will decompress the file to it's original state, Recompressing is also included but Keep in Mind the recompressed file will be different that the actual file including crc and the size.
### Compile:
Download the Source code and Run build.bat
